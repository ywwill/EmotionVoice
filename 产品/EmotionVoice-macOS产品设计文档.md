## 1. Executive Summary

### 1.1 产品愿景

**EmotionVoice** 是一款面向内容创作者、播客主播、有声书制作者和企业的 macOS 原生应用——通过阿里云 Qwen-Audio-TTS 模型实现「情感驱动的语音合成」，让文字瞬间转化为带有情感、温度和表现力的专业级语音内容。

### 1.2 核心价值主张

> **「让文字开口说话，让声音传递情感」**

| 传统 TTS | EmotionVoice |
|-----------|--------------|
| 机械、冷冰冰 | 20+ 情感表达，自然流畅 |
| 单一音色 | 500+ 精选音色库 |
| 只能普通话 | 20+ 语言 + 20+ 方言 |
| 复杂参数调优 | 自然语言指令控制 |
| 纯文字转语音 | 情感标签 + 富语言效果 |

### 1.3 版本变更说明 (v1.1)

| 变更项 | 原方案 | 新方案 | 原因 |
|--------|--------|--------|------|
| 声音复刻 | 内置复刻功能 | **移除** | API额度限制，500音色已足够 |
| API配置 | 用户配置Key | **内置** | 写在代码中或服务端获取 |
| 定价模式 | 订阅制 | **积分制** | 消耗型，按需付费更灵活 |

### 2.1 两个模型对比

| 特性 | qwen-audio-3.0-tts-flash | qwen-audio-3.0-tts-plus |
|------|---------------------------|--------------------------|
| **定位** | 轻量级快速合成 | 高质量专业合成 |
| **系统音色** | 9个 | 2个（旗舰） |
| **基础音色** | 500+ | 500+ |
| **音频质量** | 标准 | 高质量 |
| **延迟** | 更低 | 较低 |
| **价格** | 更便宜 | 稍贵 |

### 2.3 macOS 平台模型推荐

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                          💡 推荐方案：qwen-audio-3.0-tts-plus                        │
├─────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
│  理由分析:                                                                          │
│                                                                                     │
│  1. 用户群体匹配                                                                    │
│     └── macOS 用户多为专业创作者，对音质要求高于对延迟的敏感度                        │
│                                                                                     │
│  2. 内容质量优先                                                                    │
│     └── 播客、有声书等内容需要高质量输出，专业音色更合适                              │
│                                                                                     │
│  3. 成本可接受                                                                    │
│     └── 专业用户愿意为质量付更多，500+基础音色已满足选择需求                           │
│                                                                                     │
│  4. 应用场景特点                                                                    │
│     └── macOS 非实时对话场景，对延迟要求相对宽松                                      │
│                                                                                     │
│  ──────────────────────────────────────────────────────────────────────────────    │
│                                                                                     │
│  ⚠️ 可选方案: 提供用户选择                                                            │
│                                                                                     │
│  • 默认使用 Plus (高质量)                                                            │
│  • 用户可在设置中切换为 Flash (快速)                                                 │
│  • 根据使用场景灵活选择                                                             │
│                                                                                     │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.4 最终决策

| 推荐模型 | qwen-audio-3.0-tts-plus |
|----------|--------------------------|
| **默认理由** | 高质量、专业音色、适合内容创作 |
| **可选** | 用户可切换至 Flash (低延迟场景) |

### 6.3 技术选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **UI 框架** | SwiftUI | 原生声明式 UI，macOS 14+ 最佳适配 |
| **并发处理** | Swift Concurrency | async/await, Actor 模型 |
| **网络层** | URLSession + WebSocket | 原生网络，支持流式 |
| **本地存储** | CoreData + SQLite | 结构化数据 + 音频缓存 |
| **音频处理** | AVFoundation | 播放、波形分析、格式转换 |
| **积分存储** | UserDefaults + 服务端验证 | 本地缓存 + 服务端校验 |
| **API 调用** | 内置 Key / 服务端中转 | 安全灵活 |
