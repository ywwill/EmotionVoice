## 4. 五处本地化处理（`prepare_ipad_real.py`）

繁体真机图 1/2/3 的**界面**已是繁体，但用户内容不会随界面语言翻译：
4 历史卡与 5 播放详情仍是简体稿（用户点名要换成繁体）。其余按全组既定规则处理。

### ① 用户点名的「4」— 历史记录

真机 16 张卡全是同一条简体标题「清晨，当你被手机闹钟…」。换成 **16 条不同繁体记录**
（清晨，當你被手機鬧鐘喚醒 / 新品開箱 · 便攜藍牙音箱 / 睡前故事：小熊的月亮 …），
音色名与标题按台港用词与繁体字形重写（龍安靈心 / 龍安魯風 / 風月瑤 / 瑩松柳 …）。

- 头像规则与简体一致：**音色名末字的白色汉字**（龍安靈心 → 心、龍安魯風 → 風），不是图形符号。
- 组头按真机写「昨天 16 筆」；统计条 / chips / 底部标签栏保留真机繁体原样，只换卡片数据。
- 时长与大小沿用简体组，合计约 6.9 MB 与顶栏「6.81 MB」自洽。

### ② 用户点名的「5」— 播放详情

| 位置 | 原图（简体用户内容） | 成片 |
|---|---|---|
| 顶部文件名 | 清晨，当你被手机闹钟 副本 | **清晨，當你被手機鬧鐘 副本** |
| 元信息 | 130 字 · 4 句 | **154 字 · 5 句**（随新文稿重算） |
| 正文两行 | 清晨，当你被手机闹钟唤醒…AI 早已不是科幻电影中的遥远想象… | 繁体重写：清晨，當你被手機鬧鐘喚醒，螢幕根據你的睡眠週期… |

- 用词按 `zh-HK.lproj` 习惯：螢幕 / 軟體 / 即時路況 / 遙遠想像 / 身影，不做纯 s2t。
- **正文左右铺满**（沿用英文 v1.1 口径）：整段自然换行 + `text-align-last:justify`，
  两行右端实测 x≈2086 / 2078，文本区 98…2088，右侧不再空 225px；词距只有几像素微调。
  ⚠️ 154 字是量过的：多了会折出第 3 行溢出卡片（wipe 只到 y=1100）。
- 界面标签（時長 / 格式 / 積分 / 音色 / 已暫停 / 從頭播放 / 複製 / 重新命名 / 複製音頻 / 刪除）
  **保留真机繁体像素**，只有用户内容被替换。
- 真机文件名里的「副本」保留（与简体版一致）；英文版才去掉 `- Copy`，因为英文直译在商店图里
  看起来像未整理的测试账号。

### ③ 02 抹掉具体数量

真机筛选行是「全部分類 **599** ⌄」。按全组禁令（不写具体音色 / 语言数量），抹掉 599 并把
下拉箭头重画在文字右侧。⚠️ 繁体「類」右端约 x257，wipe 必须从 **x260** 起，
不能沿用简体版的 x258（会切掉繁体字的抗锯齿边缘）。右侧「♡ 2」收藏数保留。

### ④ 03 与 01 去重（沿用 v3.1 结论）

繁体真机 01/03 左栏都是 1399 字 AI 稿 + 4 色情绪标签，逐字相同，缩略图里几乎像同图传两遍。

| | 01 | 03 |
|---|---|---|
| 左栏 | 彩色情绪标签密布 | 13 行《城市漫遊》口播稿，**无标签** |
| 字数 / 积分 | 1399 字 · ≈ 50.38 | **253 字 · ≈ 9.11** |
| 右栏 | 参数滑块 | 語言 chips / 描述預設 + 已填指令（33 / 1,000） |

指令按台港用词：「用溫柔的女聲，語速放慢，像講睡前故事；／結尾稍微上揚，帶一點期待感。」
积分按真机比例 `50.38 / 1399` 换算，与 App 计费口径一致。
⚠️ 繁体描述框比简体高 13px（chips 文案长度不同），CSS 只覆盖 `top/height`，其余沿用简体样式。

### ⑤ 状态栏

繁体真机状态栏是「11月7日 **週六**」，本身已是繁体 → **保留真机像素，不 wipe**。
（英文版才需要把「11月7日周六」换成 `Sat Nov 7`。）

## 5. 实现方式

- ⚠️ **繁体绝不能走 `localize_en()`**：那套覆盖层会把整页写成英文（`EN_DATE` /
  `EN_PLAYER_TEXT` / `EN_HIST` / 英文头像规则）。`prepare()` 已拆成三条独立分支：
  `zh-Hans → 简体路径`、`en-US → localize_en()`、`zh-Hant → localize_hant()`。
- `localize_hant()` = 02 的 PIL 抹除 + 03/04 的 Chrome RGBA 透明覆盖层 + 05 的卡片区重绘；
  01 完全不动。
- 所有繁体覆盖层字体统一 `HANT_FONT = PingFang TC / PingFang HK`；
  05 复用 `render_cards()`，已参数化 `hist / css / tpl / tag`，简体路径走默认值**逐字节不变**。
- 04 的三块 wipe：标题 `(860,62)-(1380,124)` 用页面底色 `#F5F1FE`，
  元信息 `(80,932)-(520,982)` 与正文 `(80,990)-(2120,1100)` 用纯白 `#FFF`（采样自真机卡片）。
- 真机源 `real/zh-Hant/` 只读，产物写 `raw/zh-Hant/`；任何命令都不会覆盖用户原图。
