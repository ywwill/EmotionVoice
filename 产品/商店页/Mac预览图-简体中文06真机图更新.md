## 入口（两个新脚本，主生成器零改动）

```bash
cd 产品/商店页/素材
python3 prepare_mac_zh_real.py      # 真机源 → html/zh/win-06.png + 4.png
python3 gen_mac_zh06.py --export    # 重建 html/zh/06.html 并导出 06 PNG
```

`gen_mac_zh06.py` 会自动调用 prepare，所以平时只跑第二条即可。
它复用 `gen_previews.py` 的 `CSS` / `page_image` / `export`，
保证版式与主生成器逐字一致；导出时用 `only={"06"}`，
**简体 01–05 与英文 6 张一张都不重渲**。

产物：

- `素材/mac_zh_real/06-projects.jpg` —— 只读源图，`1920×1145`
- `素材/html/zh/win-06.png` —— 新 HTML 引用，`2112×1260`
- `素材/html/zh/4.png` —— 同一份，兼容主生成器历史 HTML 的 `<img src="4.png">`
- `素材/html/zh/06.html` —— 布局页，`img src="win-06.png"`

   （繁体 `06-projects.jpg` 也是纯窗口形态，两者裁法一致。）

   简体图实测 `win y1005` 之后全是纯底色，最后一行「幕里带淡金光，骗不了人。」

   全量重渲会把中英 12 张全部改动。
