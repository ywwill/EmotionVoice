## 01 · 输入区文稿（对齐 v4.5 版式）

`LINES_HANT` 与 `LINES_ZH` / `LINES_EN` 一一对齐：

- **16 行正文 + 2 个段落空行 = 18 显示行**，行距 62 / 行高 42，行宽 = 文字自然宽度。
  ⚠️ **禁铺满**：删掉所有 `letterSpacing` 拉伸 JS / `justify`，短句与段落末行故意留白。
- **12 个语气徽章**只在语气切换首行出现，同色胶囊跨行延续不重复徽章：
  興奮 / 好奇 / 憤怒 / 嚴肅 / 耳語 / 驚恐 / 極快 / 共情 / 調皮 / ASMR / 極慢 / 疲憊。
- **5 个拟声 pill** 嵌在句子中途：大笑 / 哼聲 / 嘆息 / 倒吸氣 / 咯咯笑。
  ⚠️ 禁两个语气徽章并排。
- 标签全部来自 `Shared/Models/Constants.swift` 的 `emotions` + 7 个官方 `richLanguageTags`，**禁自造**。
  底部 24 情绪 + 7 拟声 chips 现在是**真机原生繁体**，不再由 `tagbar_html()` 重绘。
- 复用中文分支 raw 坐标（`_studio_overlay("zh")`，`scale=2112/3456`），
  计数「753 字」、积分「≈ 30.2」与简体版一致（繁简一字对一字，字符数不变）。

### 06 详情卡片底部半行字清理（v3 新增）

真机文本容器会把超长文稿最后一行裁成「半行」（缩略图可见，像渲染瑕疵）。
`prepare_mac_hant_real.py` 的 `clean_card_bottom()` 做最小清理：

- **只擦除、不贴字、不改任何文案**：整块复制卡片内另一段实测无文字的纯底色条带
  win `y886..908`（22px）到 `y963..984`，横向 JPEG 纹理原样保留。
- 文字整行止于 win y960，半行在 y965..980，卡片底边约 y1002；
  擦除区 `(957,963)-(1832,984)` 全在卡片内、不碰圆角。
- ⚠️ 别铺单色（横向色带），更别**按列取色**（JPEG 逐列噪声会被拉成竖条纹，
  v3 首轮实测比半行字更显眼）。整块 `paste` 才无痕。

## 禁令 / 踩过的坑（v1 → v3）

1. ⚠️ `dominant()` 收的是 `(x,y,w,h)`，`roi` 是 `(x0,y0,x1,y1)`；
   `multi` 分支曾直接传 roi → crop 到图外、PIL 补纯黑 → wipe 刷出 `#000000` 大黑块。
2. ⚠️ `dominant()` **只统计暗色像素**（<88）；早期回退「全部像素」时，
   ROI 压到头像方块 / 橙色播放键会把 wipe 刷成白块。
3. ⚠️ 别在 `ui_overlay()` 末尾无条件注入 `UI_CSS`：会激活 06 那些坐标估出来的 B 块。
4. ⚠️ 别在 06 继续用 HTML 覆盖层擦底图正文：层叠顺序不可靠，
   实测出现「繁体 + 简体」双层字。改在图片层擦净。
5. ⚠️ 01 换真机图后 wipe 底色必须动态采样，硬编码 `gp.CARD_BG` 会留色差矩形。
6. ⚠️ 06 真机图必须整幅缩放，别套 `(58,39)-(1862,1114)`。
7. ⚠️ 清理半行字禁按列取色（竖条纹），用整块纯底色条带 `paste`。
8. ⚠️ 原生繁体窗口上禁挂任何贴字层（双层字 / 补丁块）。
