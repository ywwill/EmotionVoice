## 0. 一句话结论

v1 自绘样张 → v2 六张全换真机 → **v3 收敛为 5 张连续编号**（去掉信息密度最低的生成浮层，历史卡头像改为音色名末字的白色汉字）→ **v3.1 解决 01/03 重复**：03 换掉与 01 逐字相同的左栏 895 字稿，并在右栏描述框填入真实语音指令，让「说出来就行」在画面里真的发生。

## 1. 五张字幕

| # | H1（两行） | H2（一行） | 画面（真机） |
|---|---|---|---|
| 01 | 按句加情绪，<br>**文字才读得像人** | 情绪标签插在哪一句，就只影响哪一句 | 创作页·**参数侧栏状态**：左栏带 4 色情绪标签，右音色/语速/音量/格式/采样率 |
| 02 | 海量音色，<br>**先听再选** | 按名字、特质或语种搜索，常用的收进收藏 | 音色库（已抹掉「全部分类 599」） |
| 03 | 不会调参数？<br>**说出来就行** | 选好语言与描述预设，一句话描述声音 | 创作页·**指令侧栏状态**：左栏是另一篇无情绪标签的口播稿，右侧语言 chips / 描述预设 / **已填好指令的描述框** |
| 04 | 回听、倍速、导出，<br>**都在一屏** | 波形拖定位，倍速、格式、音色一眼看全 | 播放详情（二级页，无标签栏） |
| 05 | 生成过的，<br>**都给你留着** | 按日期分组、收藏与搜索，随时回听和导出 | 历史记录 16 张**互不重复**的音频卡，头像为完整汉字 |

**为什么删掉生成浮层**：从转化视角，预览图的每一格都要么传达一个差异化能力、要么推进下载决策。「正在接收」浮层展示的是一次性进度状态，缩略图里既读不清参数、也不构成卖点，反而是六张里信息密度最低的一格。移除后 5 张各自有独立主题（情绪 / 音色 / 语音指令 / 回听 / 留存），且不违反 Apple 的 1–10 张范围。`real/04-generate.png` 保留只读存档，随时可恢复。

字幕与 iPhone 组只在 03 副标题（真机叫「描述预设」）有差异，其余逐字一致。全组不写具体能力数量、不写 iOS 端没有的声音复刻。

**创作页三合一**：真机的「输入框 / 音频参数 / 语音指令」是**同一个界面**——左栏固定，右栏在参数与指令间切换。01 与 03 是它的两种侧栏状态，不再拆成独立界面。参数卖点由 01 画面承载，不再单独占一格字幕。

**v3.1 为什么换 03 左栏**：真机两次截图用的是同一篇 895 字《智能之光：AI时代的机遇与思考》，连 4 色情绪标签都逐字相同；在商店缩略图尺寸下，01 与 03 只靠右栏区分，几乎像同一张图重复上传。现在按「另一次创作」处理 03：01 是**彩色标签密布 + 参数滑块**＝手动精调，03 是**纯文本 + 已写好的一句指令**＝一句话搞定。两页的视觉纹理、内容、右栏动作三者都不同，且各自印证自己的字幕。

## 3. 三处像素级优化（`prepare_ipad_real.py`）

### 02 抹掉能力数量
真机筛选行是「≡ 全部分类 **599** ⌄」。按全组禁令（不写具体音色/语言数量），把 x 258–362 / y 248–302 涂成胶囊白底，并在「全部分类」右侧重画下拉箭头。右侧「♡ 2」收藏数保留。

### 03 换左栏稿 + 填语音指令（v3.1）
用 Chrome 渲染一张 **2224×1668 全透明覆盖层**（`--default-background-color=00000000`，输出 RGBA 后 `alpha_composite`），只改三块，其余真机像素不动：

- **左栏**：用与真机卡片同形的白色圆角矩形（x65 / y145 / 1340×1245 / radius 24）整块盖掉 895 字 AI 稿，重画 13 行**无情绪标签**的《城市漫游》口播稿（253 字），右上角字数 `895 字 → 253 字`，底部 `预计 ≈ 33.54 → ≈ 9.48`（按同比例换算）。⚠️ 不能只盖文字区：旧彩色句段胶囊的圆角边缘会露在 x<100 与 x>1375 两侧，形成红/绿弧形残影。
- **右栏描述框**：真机是空占位符「用一句话描述你想要的声音」+ `0 / 1,000`；改成深色正文「用温柔的女声，语速放慢，像讲睡前故事；／结尾稍微上扬，带一点期待感。」+ `33 / 1,000`。⚠️ 两行手动断句，别让自动换行把「睡前故事」拆开。
- 语言 chips / 描述预设 / 「仅支持中文和英文输入」/ 顶部标签栏 / 底部按钮一律保持真机原样。

### 05 历史记录数据 + 头像（v3 修正）
真机 16 张卡全是同一条「清晨，当你被手机闹钟… 龙安灵心 00:26 425.6 KB 19:53」。用 Chrome 渲染一层 2224×960 的卡片区覆盖层（`PingFang SC`，与真机同字体）替换 y 560–1520，重画组头 + 16 张卡：

- **只换数据，不动界面结构**：统计条（16 条音频 / 6.81 MB / 16 条本月）、chips（全部 16 / 收藏 0）、组头（今天 16 条）、底部标签栏全部保留真机原样。
- 16 条标题/音色/时长/大小/时间各不相同，音色名取自 `zh-Hans.lproj/VoiceCatalog.strings` 的真实条目（龙安灵心、璨竹月、朗虹沫…），头像按音色换渐变。
- ⚠️ **头像 = `voice[-1]` 的白色汉字**（龙安灵心 → 心、龙安鲁风 → 风、风月瑶 → 瑶…），46px / PingFang SC / 居中。v2 用 `AVA_SVG` 画了三笔折线，在缩略图里读作「残缺的 n」，与真机不符，v3 已删除该 SVG。
- 16 张卡大小合计约 **6.9 MB**，与顶栏「6.81 MB」自洽；时间从 19:53 递减到 09:12，符合「按时间排列」。
- 卡片样式逐像素对齐真机：白底圆角 20px、左侧 86×87 渐变头像、标题 23px、紫色音色 chip、灰信息等宽数字、右侧 62px 播放按钮。
