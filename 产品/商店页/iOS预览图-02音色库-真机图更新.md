## 2. 为什么换

旧成片用的是**更早一版音色卡**：特质文案飘在卡片右上角、没有 `599` 计数、顶上还有一行
`Flagship first, then by name`。现在的界面改成：

- 名字 + 特质在色块右侧两行，年龄 / 性别 / `Premium` 收成一行小 chip；
- 分类 chip 直接带数量（`全部分类 599`）；
- 每张卡三个动作：试听、收藏、进入详情（右下角箭头）；
- 搜索框覆盖 **音色名 / 特质 / 场景** 三个维度（**没有语种**）。

新截图信息密度更高（一屏 8 张卡 + 半行第 9 行），「海量」这个说法终于有画面支撑。

## 3. 文案

标题保留原案。副标题只写截图里真实存在的三个搜索维度（名字 / 特质 / 场景），
**禁写「语种」**——搜索框里已经没有这一项，写了就是过度承诺：

| 语言 | 标题 | 副标题 |
| --- | --- | --- |
| 简中 | 海量音色，**先听再选** | 按名字、特质或场景搜索，先试听再收藏 |
| 繁中 | 海量音色，**先聽再選** | 按名字、特質或場景搜尋，先試聽再收藏 |
| 英文 | Hear it before / **you pick it** | Search by name, trait or scenario, then preview |

三个版本与手机内 placeholder 逐字对应：
`搜索音色名 / 特质 / 场景`、`搜尋音色名 / 特質 / 場景`、`Search voice name / traits / scenario`。

繁中页强制 `PingFang TC`（否则「聽」「選」「種」会落到简体字形）；英文页走 Helvetica 栈。
版式 CSS、设备框、字号、圆点位置（第 2 个高亮）**逐字沿用现有 6 张**。

## 4. 技术处理

1. **1:1 贴图**：源图 885×1920 → cover 缩放到设备屏幕的精确像素 `1007×2214`
   （`.device` 1033×2240 − padding 13×2），视口 1320×2868 / DPR 1 下浏览器不再二次缩放。
2. **轻锐化**：源图比屏幕窄，放大约 15.3%，收尾加 `UnsharpMask(radius=1.2, percent=50)`，
   小字（`Search voice name`、`25 yrs`）边缘明显更实，未见白边或噪点。
3. **状态栏统一 9:41**：三张原图是 10:52 / 10:53，同组其余 5 张都是 9:41。
   底色实测纯平 `#F5F1FF`（sd=0），整块刷底重绘无补丁；字号由「墨迹高 35px」反解
   SFNS **Semibold 47**，墨迹框左上对齐原位。
4. **顺带擦掉旁路的静音图标**：原图时间右侧有一个「铃铛加斜杠」，同组其它 5 张都没有，
   一并在刷底时抹掉，状态栏现在只保留 时间 / 信号 / Wi-Fi / 电量，与全组一致。
5. **漏画守卫**：headless 偶发视口最后 21px 没画完（白条），`html{background:#F3EFFC}` 兜底 +
   导出后检查底部 6 行，整行近白就重渲（最多 4 次）。

## 5. 用法

```bash
cd 素材
python3 gen_ios_02.py                    # 三语全跑：prepare → statusbar → html → export → sheet
python3 gen_ios_02.py --lang zh-Hant     # 只换某一语的图
```

⚠️ 换图必须从 `prepare` 重跑（`src/<lang>/02-voices-src.png` 是源），
只跑 `export` 会用旧的预缩放图。源图归档在 `ios-02v2/src/<lang>/`。

## 7. 两点原样保留（没做手脚）

1. **顶部没有灵动岛**：三张源图来自无灵动岛机型，状态栏是「时间 + 信号 + 5G + 电量」
   （98% 绿色为充电态）直贴屏幕。
   同组 01 / 03 / 04 / 06 有黑色药丸。我按真机原样保留，没有贴假硬件——若要求组内完全一致，
   需要换有灵动岛机型重截三张。
2. **截图自带 `599` 计数**：文案里不写任何具体数量（全组约定），但截图里的 `全部分类 599`
   是真实 UI，原样保留。
