# iOS 预览图 05（播放界面）—— 三语合成

> 旧 05 用的是**早期播放器 UI**（上一首/下一首、1.0x、时长/格式/大小/音色四宫格），
> 现在的播放器是「大波形 + 15s/5s 跳转 + 倍速 + 逐字高亮跟读 + 句子卡片点句跳转」。
> 本脚本用真机截图合成 1320×2868 商店图，**直接覆盖同名文件**。

## 2. 入口

```bash
cd 产品/商店页/素材

python3 gen_ios_05_v2.py                       # 三语全跑
python3 gen_ios_05_v2.py --lang zh-Hant        # 只重做某一语（换图时最常用）
python3 gen_ios_05_v2.py --step prepare        # 只做截图预缩放
python3 gen_ios_05_v2.py --step export         # 只重渲 Chrome
```

`prepare` 每次都从 `ios-05v2/src/<lang>/05-playback-src.png` 重新裁切，
所以 `statusbar` 改过的状态栏不会被叠加两次——**换图后必须从 `--step prepare` 重跑**（或直接跑默认 all）。

目录：

```
ios-05v2/
  src/<lang>/05-playback-src.png   原始截图归档（885×1920）
  raw/<lang>/05-playback.png       预缩放 1007×2214（设备屏幕 1:1 像素）
  html/<lang>/05.html              合成页（1320×2868）
  _05-三语总览.png                  审阅用
```

## 5. 状态栏为什么改成 9:41

原图分别是 15:53 / 16:01 / 19:06，同组六张里其它五张都是 9:41，
直接放上去会像「三次不同时刻的抓拍」。处理方式：

- 实测状态栏底色是**纯平** `#F5F1FF`（三条带 sd=0.0），所以**整块刷底**再重绘，不会留补丁/竖条纹；
- 字号不是猜的：量出原时间字符串的墨迹高度（h=31），反解 SFNS Semibold 的字号（=41），
  再把「9:41」的墨迹框**左上对齐**到原墨迹框，避免 side bearing 让文字整体漂移；
- 只改时间，**信号 / Wi-Fi / 电量原样保留**（电量是绿色充电态，属真机实拍，未改写）。

## 6. 技术要点（踩过的坑）

- **1:1 像素**：视口 1320×2868 / DPR=1，`.device` 1033×2240 减 padding 13×2 = 屏幕 **1007×2214**。
  截图先 cover 缩放（885×1920 → 1021×2214，等比 1.1531）再居中裁 7px/边，
  浏览器里 1:1 贴图，比旧页（1179 宽图缩到 1007）更锐。
- **Chrome 必须 `--no-sandbox`**：本环境的进程沙箱不允许 Chrome 起自己的 sandbox，
  不加会 `sandbox initialization failed` → `GPU process isn't usable` → SIGTRAP。
- ⚠️ **headless 偶发「视口最后 21px 没画完」露出纯白条**：iOS 这套底色是浅色，
  白条会非常显眼。`export()` 出图后检查最底 6 行，若整行都 ≥248 就重渲（最多 4 次）。
- 出片统一 `convert("RGB")`：App Store 不接受带 alpha 的 PNG。
- 版式 CSS、设备框、标题字号、底部圆点**全部逐字沿用 01–06 现有页面**，保证六张一套。

## 8. 已知局限

1. **中文**：歌词卡首行是上一句残尾「仁。。」（卡片停在滚动中间态）。
   想要更干净可重截一张「歌词卡滚到顶部」的图，丢 `ios-05v2/src/zh-Hans/` 再跑 `--lang zh-Hans`。
2. **英文**：正文是测试文案（"Here's an English description of A I…"），标题被截成 "Here's an"。
   换成自然的英文示例会明显提升营销观感。
3. 源图是 885×1920 的 JPEG，放大 1.15 倍后小字略软；有 1179×2556 原始 PNG 可换进 `src/` 重跑。
