## 0. 适用范围与一句话结论

- 面向 **台湾、香港、澳门** 三个商店（ASC 里只有一个 `繁体中文 zh-Hant` 本地化，三地共用）。
- 一句话：**字幕按台港用词重写，界面文案取 App 自己的 `zh-HK.lproj`**——不是把简体稿机械转字。
- 与简体版的关系：构图、设备框、标题位置、进度点完全一致；差异只在文字层（字幕 + 界面文案 + 字形）。

H1 每行 4–9 字（106px 字号、1080px 可用宽），H2 ≤ 20 字（42px），实测无折行。

## 2. 界面繁化怎么做的（这一节是全部要点）

### 2.1 为什么不能用纯简繁转换

设计稿是简体，直接 `s2t` 会得到「項目 / 導出 / 文件 / 採樣率 / 搜索 / 加載 / 設置」——这七个词 App 繁体界面**全都不是这么写的**：

| 简体 | s2t 直转（错） | App zh-HK 实际（对） |
|---|---|---|
| 项目 | 項目 | **專案** |
| 导出 | 導出 | **匯出** |
| 文件 | 文件 | **檔案** |
| 采样率 | 採樣率 | **取樣率** |
| 搜索 | 搜索 | **搜尋** |
| 加载 | 加載 | **載入** |
| 设置 | 設置 | **設定** |
| 默认 | 默認 | **預設** |

用户下载后看到的是 `zh-HK.lproj` 里的文案，商店图必须与之一致，否则「图上是設置、App 里是設定」。

### 2.2 三层替换（`gen_ios_previews.py`）

1. **`HANT_DICT`｜词典层**：运行时解析 `EmotionVoice/EmotionVoice/zh-HK.lproj/Localizable.strings` + `VoiceCatalog.strings`，得到「简体原文 = 繁体译文」500+ 条。这是唯一权威来源，不手工造词。
2. **`HANT_OVERRIDE`｜样张层**：设计稿特有的假数据与分镜文案（「全部生成音頻 · 按時間排列」「繼續載入更早的記錄…」「十月活動旁白（舊）」等），strings 里没有，按同一口径补。
3. **单字兜底层**：仍未命中的零星汉字走 OpenCC `s2t` 逐字映射；`HANT_CHAR_FIX` 再把 s2t 的旧字形改回台港现用字：

| s2t 输出 | 改为 | 依据 |
|---|---|---|
| 爲 | **為** | 现代港澳台通用 |
| 衆 | **眾** | 同上 |
| 裏 | **裡** | App 里「裡」出现 1 次、「裏」0 次 |
| 啓 | **啟** | App 用「啟」 |
| 臺 | **台** | App 里「台」21 次、「臺」0 次 |

替换顺序：整节点精确命中 → 词组子串（长 key 优先）→ 单字兜底。

### 2.3 字形

设计稿 `--font` 首选 `PingFang SC`，繁体字会被简体字体的字形影响（「骨」「門」等部件写法不同）。繁体版注入：

```css
:root{--font:"PingFang TC","PingFang HK","Helvetica Neue",-apple-system,system-ui,sans-serif}
```

字幕页（HTML 母版）同样换成 `PingFang TC`，`html lang="zh-Hant"`。

### 2.4 02 音色库：退回设计稿样张

简体版的 02 是真机截图，繁中没有对应真机图，处理方式与 en-US 一致：设计稿音色库界面 + `EXTRA_VOICE_CARDS_HANT` 补 4 张卡片（用 `zh-HK/VoiceCatalog.strings` 里的真实音色：蓉芷荷 / 璨竹月 / 風月瑤 / 朗虹沫）。第一张卡片描述缩短为「溫柔知性女聲，適合有聲書」，避免繁体下孤字换行。

### 2.5 校验

Chrome `--dump-dom` 逐页提取可见文本，用「s2t 会变且修正后仍不等于自身」的 320 个简体专有字做字符类扫描：

```

```

```
产品/商店页/
├─ iOS预览图-繁体版分镜.md                     ← 本文
└─ 素材/
   ├─ gen_ios_previews.py                      ← 加 --locale zh-Hant
   ├─ ios_previews/
   │  ├─ raw/zh-Hant/{studio-1,voices-1,studio-4,studio-3,shot-favorite,shot-default}.png

   │  └─ _320px自检-zh-Hant.png
   └─ ios-1320x2868/zh-Hant/01…06.png
```

```bash
cd 产品/商店页/素材

# 只重出繁中（界面 + HTML + PNG）
python3 gen_ios_previews.py --locale zh-Hant --export

# 三套一起重出（默认行为：zh-Hans / en-US / zh-Hant）
python3 gen_ios_previews.py --export

# ⚠️ 换真机截图后：必须带 --html-only，否则会重新从设计稿提取并覆盖新截图
python3 gen_ios_previews.py --locale zh-Hant --html-only --export
```

依赖：`pip3 install opencc-python-reimplemented`（单字兜底用；未装时只走 zh-HK 词典，脚本会打印警告）。
