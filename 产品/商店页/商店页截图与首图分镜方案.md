# Emora — Mac App Store 截图顺序与首图分镜方案

> 日期：2026-10-21　平台：Mac App Store　配套文案：`商店页文案-ASO优化审计.md`
> 画面全部对应当前版本真实界面，不含概念插画。

---

## 0. 规格口径（先确认再出图）

| 项目 | 口径 | 说明 |
|---|---|---|
| 画幅 | **16:10 横版** | Mac 专用，与 iPhone 竖版不通用，不能裁切复用 |
| 尺寸 | 2880 × 1800 px（推荐） | 同时接受 2560×1600 / 1440×900 / 1280×800；**只传一套最高尺寸即可**，ASC 自动缩放 |
| 数量 | 1–10 张 | 建议 **6 张**，前 3 张会被带进搜索结果 |
| 格式 | PNG（推荐）或 JPEG | RGB，**禁止 alpha 通道与透明背景** |
| 体积 | 单张 < 10 MB | 2880×1800 PNG 通常 2–6 MB |
| 画面要求 | **必须是真实 macOS 窗口** | 用 iOS 界面或纯插画会被拒；可以放在背景上、可以加字幕，但窗口本身要真 |

⚠️ 尺寸会随 Apple 调整，**上传前以 App Store Connect 上传页的实时提示为准**，本表用于设计与归档。

## 1. 首图决策

首图不是最好看的画面，是"一眼能说明这是什么"的画面。三个问题逐条过：

| 问题 | 判断 | 依据 |
|---|---|---|
| 一眼看出品类吗 | 要 | 画面里必须有**文本 + 波形/播放条**，否则像笔记软件 |
| 一眼看出卖点吗 | 要 | 必须看到**彩色情绪标签压在句子上**，这是唯一差异点 |
| 一眼看出品质吗 | 要 | 用真实深色界面，不用示意图 |

### 三个候选

| 方案 | 画面 | 优势 | 风险 |
|---|---|---|---|
| **A（主推）** | 工作台主界面，编辑区里 3 个句子各带一个不同色情绪标签（兴奋/严肃/大笑），右侧情感面板展开，底部播放条有波形 | 品类、卖点、品质三问全过；纯实机 | 信息较多，缩略图下要控制视觉焦点 |
| B | 同一工作台，但只截**编辑区特写**：一句文字 + 标签胶囊 + 选中态高亮，其余裁掉 | 卖点最聚焦，缩略图辨识度高 | 品类信号弱（看不出是配音工具），需靠字幕补足 |
| C | 大字幕 + 小窗口（文字驱动型） | 标题冲击力最强 | 窗口太小看不清界面，品质感弱；Mac 端少见 |

**推荐 A 作为首版**，**B 作为 Product Page Optimization 的处理组**做 A/B——第 1 轮就测这两张。

⚠️ 不建议做"有情绪 vs 没情绪"的左右对比示意图：声音的差别画不出来，做成对比插画就不是实机画面，有被拒风险。要表达差异，用标签颜色 + 波形起伏的实机状态来体现。

## 2. 六张图的顺序与信息分配

每张图只承担一个任务，六句话互不重复。

| # | 任务（一句话） | 画面内容 | 字幕（中 / 英） | 真实性核对 |
|---|---|---|---|---|
| **1** | 这是什么 + 最强卖点 | 工作台：编辑区 3 句各带一个情绪标签胶囊，右侧情感面板，底部播放条波形 | 按句插情绪，文字就有了语气 / Tag emotion per line | 标签胶囊为 `EmotionTokenTextView` 实绘；情感面板见 `Constants.emotions` |
| **2** | 音色规模与挑选效率 | 音色库：筛选条（语言/性别/场景）展开，卡片网格，一张卡处于试听态 | 599 个音色，先听再选 / 599 voices — preview before you pick | `VoicesLibraryView` + 筛选 code 列；数字需与 `basic_voices.json` 一致 |
| **3** | 门槛：不会调参数也能用 | 语音指令区：输入框写着一句自然语言描述，下方 6 个预设模板可见 | 不会调参数？说出来就行 / Just say it in plain words | `Constants.nlPresets` 6 个预设真实存在 |
| **4** | 产出：边写边听 + 导出 | 生成完成后播放详情：波形、播放控制、导出按钮（MP3 / WAV 可见） | 边生成边听，一键导出 MP3 / WAV / Stream it, export MP3 or WAV | 流式合成 + `HistoryView` 导出菜单真实存在 |
| **5** | 覆盖语种与方言 | 音色库切到方言筛选：粤语、四川话、东北话音色卡在列 | 中文、英文，还有粤语、四川话、东北话 / Mandarin, English, and dialects | `nlLanguages` 24 条；方言音色在音色库内 |
| **6** | 留存 + 收尾号召 | 历史记录列表：多条生成记录按时间排列（文件名/时长/音色/状态），右下角品牌标识 | 生成过的都留着，随时回听 / Everything you made, one click away | `HistoryView` 真实存在；不能出现价格 |

**关于第 6 张**：原计划用浅色模式做对照图，核查后发现 `EmotionVoiceApp.swift` 有 `.preferredColorScheme(.dark)`，**App 当前强制深色，截不出浅色画面**——所以整组统一深色，第 6 张改为补上"历史记录留存"这个文案承诺，并承担收尾号召。Apple 建议"支持深色至少展示一张深色"，全深色组天然满足。

> ⚠️ 若后续版本开放浅色外观，再补一套浅色图；在那之前不要为了凑对照而伪造浅色画面。

## 3. 首图分镜（方案 A，可直接交给设计执行）

画布 2880 × 1800，16:10。

```
┌────────────────────────────────────────────────────────────────┐
│  ← 180px 安全边距 →                                             │
│                                                                │
│         按句插情绪，文字就有了语气                    ← H1      │
│         一句话一个语气，插在哪句就影响哪句            ← H2      │
│                                                                │
│   ┌──────────────────────────────────────────────────────┐    │
│   │ ● ● ●   Emora — 语音合成工作台                        │    │
│   ├────────┬─────────────────────────────────────────────┤    │
│   │ 音色库 │  [兴奋]过去几年，TTS 技术从机械朗读…          │    │
│   │ 工作台 │                                              │    │
│   │ 项目   │  [严肃]但真正让它质变的，是…                  │    │
│   │        │                                              │    │
│   │        │  [大笑]听起来是不是很酷？                     │    │
│   │        │                                              │    │
│   │        ├─────────────────────────────────────────────┤    │
│   │        │ 😊 情感控制                    🌐 语言与采样率│    │
│   │        │ [兴奋][严肃][耳语][ASMR][大笑][叹息]          │    │
│   │        ├─────────────────────────────────────────────┤    │
│   │        │ ▶  ▁▂▃▅▇▅▃▂▁▂▃▅▆▅▃▂▁  00:03 / 00:18  导出    │    │
│   └────────┴─────────────────────────────────────────────┘    │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 标题区 | 占画面上部约 22%；H1 字号约 **110–130 px**（在 2880 宽画布上），H2 约 52 px，H1/H2 行距 1.25 |
| 窗口区 | 下部约 72%，窗口宽约 2400 px，居中，圆角 12 px，投影 opacity 0.35 / blur 40 |
| 背景 | 与 App 深色一致（#0E0F12 → #15171B 竖向渐变），禁止纯黑或花哨纹理 |
| 焦点引导 | 编辑区三个标签用**不同情感色**（琥珀 / 蓝 / 橙）实拍，不做额外高亮圈 |
| 禁止 | 不加箭头、不加手指图标、不加"New"角标、不出现价格与积分数字 |

**缩放自检**：把成品缩到宽 320 px 看一遍——H1 应仍可辨认，三个彩色标签应仍看得出"文字上有色块"。做不到就把 H1 加大或缩短文案。

## 4. 文字叠加的统一规则（全组 6 张一致）

| 项目 | 规则 |
|---|---|
| 位置 | 全部**顶部居中**，窗口全部居中偏下；6 张保持一致 |
| 字数 | H1 一句话 ≤ 16 字（英文 ≤ 40 字符），H2 一行补充说明，可省略 |
| 字号 | H1 ≥ 画布宽度 3.8%（2880 宽 → ≥110 px）；H2 约其一半 |
| 对比度 | 标题与背景亮度差 ≥ 4.5:1；深色背景上用 #F5F5F7 |
| 字体 | 全组统一一种（建议 SF Pro Display / 系统字体），中英各一套但字重一致 |
| 母版 | 先出**无文字母版**，再叠文字层；多语言只需换文字层，不用重截图 |

## 5. App 预览视频分镜（20 秒，1 条）

⚠️ **最关键的一条约束**：App 预览在商店页**自动播放且默认静音**。这是一款语音产品，声音恰是卖点——所以视频必须做到**无声也讲得通**：靠波形起伏 + 字幕 + 标签颜色变化来"看见"声音变化。

| 镜头 | 时长 | 画面内容 | 屏幕文字 | 备注 |
|---|---|---|---|---|
| 1 | 0–3s | 光标敲出一句"欢迎收听本期节目"，随即插入 `[兴奋]` 标签胶囊，波形开始生长 | 一句话，一个情绪 | 前 3 秒定生死，直接进工作流，不要厂商标板 |
| 2 | 3–7s | 连续点选情感面板里的兴奋→严肃→耳语，波形粗细与颜色随之变化 | 23 种语气，随句切换 | 变化要用波形/颜色表现，别指望声音 |
| 3 | 7–11s | 切到音色库，筛选"中文 / 女声"，点一张卡的试听，波形跳动 | 599 个音色，先听再选 | 展示筛选条与卡片网格 |
| 4 | 11–15s | 语音指令框输入一句描述，点预设"有声书"，参数自动应用 | 不会调参数？说出来 | 展示 6 个预设 |
| 5 | 15–18s | 点生成，流式播放，波形从左向右实时生长 | 边生成，边听 | 体现流式，不等整段 |
| 6 | 18–20s | 导出面板弹出，选中 MP3 与 WAV，画面收尾出品牌标识 | 导出成片 | 品牌露出放结尾，不放开头 |

规格：≤30 秒，16:10（与截图同比例，可用 2880×1800；**以 ASC 上传页实时提示为准**），H.264，帧率 ≤30fps。Mac 产品页最多放 3 条预览，首版做 1 条即可。

## 6. 素材与文案的一致性核对

文案里承诺的每一条，都要能在某张图里被看见——否则就是"图上没有、字上有"，下载后会产生落差。

| 文案承诺 | 由哪张图兑现 | 状态 |
|---|---|---|
| 按句插情绪标签（23 语气 + 7 拟声） | 图 1（标签胶囊）、图 3 附近情感面板 | ✅ 图 1 |
| 599 音色、可筛选可试听 | 图 2 | ✅ |
| 自然语言指令 + 6 预设 | 图 3 | ✅ |
| 流式生成、边写边听、导出 MP3/WAV | 图 4 | ✅ |
| 方言（粤语 / 四川话 / 东北话） | 图 5 | ✅ |
| 生成记录自动留存、随时回听 | 图 6 | ✅ |
| 强制深色外观 | 全组统一深色，不出现浅色画面 | ✅ 已核实 `preferredColorScheme(.dark)` |
| 按字数计费、不绑定订阅 | **不出现在任何图上**（价格不进素材） | ✅ 刻意不上图 |
| 界面支持中英、跟随系统语言 | 图 1–5 用中文界面、图 6 可放英文界面版本（另做英文本地化套图） | ⚠️ 需另出英文套图 |

⚠️ **待办**：英文商店页需要一套英文界面的截图（同一构图、换窗口内文字）。别把中文界面截图用在英文商店页上。

## 8. 验收清单

| 验收项 | 方法 | 通过标准 |
|---|---|---|
| 首图辨识度 | 给没用过的人看图 1 三秒 | 能说出"配音工具，可以按句调情绪" |
| 信息不重复 | 逐图写一句话说明 | 六句话互不重复 |
| 小尺寸可读 | 缩到 320 px 宽观看 | H1 能读、标签色块能看出 |
| 画面真实性 | 与当前版本实机对比 | 图中功能在当前版本点得出来 |
| 规格符合 | 上传前核对 | 16:10 / 2880×1800 / PNG / 无 alpha / <10MB |
| 无价格 | 逐图检查 | 任何图上都不出现价格、积分数字、"免费"字样 |
| 外观一致 | 六张并排看 | 全组深色（App 强制 `.dark`），配色与字重统一 |
| 中英同步 | 两套图对比 | 构图一致、窗口内文案语言正确 |
