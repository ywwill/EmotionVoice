### 信息架构决策（待用户确认）
- macOS「侧边栏 5 分区（1500×900 单窗口）」→ iOS「4 Tab + 导航栈」：

## iOS 设计稿 v2 改版（用户反馈后）

### 1. 配色：Cold Luxury（琥珀金）→ Aurora Pop
- 需求原文：「优化配色，需要青春靓丽一点」。中性底改雾紫：浅色 grouped `#F5F1FE`、深色 bg `#12101F` / grouped `#0B0916`。
- **拆两套色**：文字强调（浅 `#6D3BF5` 5.9:1 / 深 `#B79AFF` 8.2:1）与装饰渐变分离。
  - `--grad-cta`（按钮，深一档）：浅 `#5B2EDB→#CE2B72`，深 `#7C4DFF→#E23C86`，白字。
  - `--grad-pop`（装饰/发光/网格点亮）：`#8A5BFF → #FF5FA2 → #FFB457`（115°）。
  - 四色分工：紫=主/CTA 起点，玫瑰=进行中/播放头/网格高亮，薄荷 `#2ED9BF`=成功与完成态顶部条，暖橙 `#FFB457`+`#FF9838`=积分计费。
- 三级文字提到 4.5:1 以上（浅 `#736D8F` 4.9 / 深 `#8E86B0` 5.1）。
- **情感 30 色不动**（沿用 macOS mapping，浅色向 `#1B1533` 压暗 62%），避免语义色被主色带跑。

### 2. 「正在接收」改居中弹窗（不再单开 Sheet）
- 需求原文：「可以只设计成弹窗，不需要单独弹出一个界面，内容太空了」。
- 方案：**331pt 居中卡片 + rgba(34,18,72,.44)+blur(7px) 遮罩**，点「生成音频」当场弹出（回归 macOS 560pt 居中弹窗的思路）；
  **进行中与完成态共用同一个弹窗**，只切换顶部 5px 渐变条（进行中=紫→玫瑰→橙，完成=紫→薄荷）、图标与内容区。
- 内容补到 7 层（原来 3 层太空）：① 音色 × 参数 chips 行（WAV / 22.05kHz / 1.0x / 128 字 / −2.40 积分）② 24 根实时波形
  ③ 大字字节数（38pt mono）+ ↑速率 ④ 不确定进度条 ⑤ 四宫格（已用时 / 数据块 / 目标 ≈412KB / 预计时长 00:24）
  ⑥ 接收网格（受宽度限制从 22 列降到 **18 列 × 5 行**，1 格 ≈4.6KB）⑦ 后台接收 / 停止生成。
- 「目标大小 / 预计时长」用 macOS `prepareGrid()` 同一估算链（字数→时长→字节），所以进度仍不确定但有可读参照量。
- 完成态额外：名称可编辑行 + 播放器卡（波形可点拖）+ 铺满的网格 + 计费行 + 分享/导出/完成。
- ✕ 与「后台接收」都只关弹窗不断连接；后台浮条保留，点「查看」回到同一个弹窗。

## 音色库分类：设计稿改为严格对照 Swift 源码（用户要求「参考 Swift 代码，不要参考 HTML」）

来源：`EmotionVoice/EmotionVoice/EmotionVoice/Models/Voice.swift`（`VoiceCategory` / `VoiceCategoryDimension`）、
`Views/VoicesLibraryView/VoicesLibraryView.swift`、`ViewModels/VoicesLibraryViewModel.swift`、`Services/VoiceService.swift`。

### 源码事实（此前设计稿画错了的部分）
- **29 个 VoiceCategory case**，5 个 dimension：旗舰(1) / 语言(2) / 适用场景(17) / 角色(4) / 年龄阶段(5)；
  视图层另渲染「收藏」「全部」→ 共 31 chip。macOS 两行 FlowLayout：第一行固定 收藏/全部/旗舰/中文/英文，第二行 = `secondaryDisplayOrder` 26 个自动换行。
- **分类是单选，不是多选**：`selectCategory` 互斥，再点同一个 → nil（回全部）；`toggleFavoritesFilter` 与 selectedCategory 互相清空。
- **「角色」维度 ≠ 同名场景 chip**：是独立 case，`roleSceneCode` 由 anime/live_stream/classic_audiobook/radio 各自派生一份，数量与对应场景相同。
- **chip 计数恒为全量**：`reloadChipCounts` 始终用空搜索词；结构键（分类/收藏）变了才重算，避免每次击键 18 次 count 查询。
- **搜索时忽略当前分类**（`reloadCurrentPage` 里 isSearching → category = nil），全库匹配；
  `matchesSearch` 只命中 4 个字段：localizedName / localizedDesc / scene.displayName / lang.displayName。
- **排序固定**：旗舰优先 → `sortKey`（当前语言展示名）字典序；**没有排序控件**。
- **没有范围滑杆**：`RangeSlider.swift` 是未挂载的孤儿文件，`VoicesLibraryView` 里没有任何引用。
- `VoiceCard`：`sceneTag()` 写了但从未调用（所以卡上不显示场景）；meta 标签是「%d 岁」+ 性别（unknown 时为空字符串）。
- 分页：`pageSize = 列数 × rowsPerPage(4)`，`updatePageSize` 用 `floor((宽+14)/(220+14))` 算列数；骨架屏固定 5×4。
