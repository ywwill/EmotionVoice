### 修复：Invalid protocol value（同日，关键）
- 用户部署后客户端报 `服务器错误: Invalid protocol value`。
- **根因**：Supabase 线上 Edge Runtime 的 Deno 版本 < 2.5，不支持
  `new WebSocket(url, { headers })`；它把第二个参数当 subprotocol 校验，
  options 对象转字符串 "[object Object]" 非法 → 构造时同步抛 `Invalid protocol value`
  → runJob 的 catch 把它包装成 task-failed 发回客户端，所以表现为「服务器错误」。
- **修法**：`dialUpstream()` 两级拨号 —— 先试原生 `{ headers }`，捕获异常后回退
  `npm:ws@8`（`new NodeWebSocket(url, { headers })`，用 `on("open"/"message"/...)` 事件，
  消息用 `isBinary` 区分文本/二进制）。`?ws=npm` 可强制走回退路径。
  日志打印 `[bailian-tts] 拨号方式: deno-native | npm:ws`。
- 本地两种方式都实测通过（native 534764B/13 片，npm:ws 542444B/14 片），`deno check` 通过。
- 教训：以后判断线上 Deno 能力，别假设与本地 Deno（2.9）一致。
