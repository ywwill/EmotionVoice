## macOS 阅读区：换行时播放底色不再熄灭
- 现象：`PlayerTranscriptView` 一行播完切下一行时，播放底色会「消失一下」再出现在下一行。
- 根因：`AudioTimeline.location(at:)` 在**句间停顿**里返回 `index = nil`（只有 previous/next），而底色 / 左侧竖条 / 时间码色全按 `isActive = cue.index == activeIndex` 画 → 停顿期间整页没有一行亮着（停顿越长灭得越久），下一句起播才重新亮。
- 改法（仅 macOS，`View/macOS/HistoryView/PlayerTranscriptView.swift`）：
  - 新增 `highlightIndex(atMs:location:)`：有当前句且有正文 → 就是它；否则（停顿 / 落在纯标签句上）交给**下一句有正文的句子**。底色、竖条、时间码、跟随滚动统一用它，不再用 `activeIndex`。
  - `visibleCues`（有正文句的 `index + beginMs`）在 `AlignedTranscript.init` 里算一次并 `let` 存住 —— ⚠️ 别改成 body 里现算（那是 10Hz 路径）；也别用 `location.next` 当交棒目标（`[clears throat]` 独占一句时界面上没有那一行，交过去等于没亮）。
  - `scrollCurrent(proxy, to:)` 简化为只吃 highlight；`.onChange(of: highlight ?? -1)` 触发 —— 滚动与高亮同一拍，全程永远一行亮着，整段播完（没下一句）才真的熄灭。
- 验证：`bash tools/ios_build.sh mac` 双 target BUILD SUCCEEDED；`/tmp/hl_check.swift` 10 条断言（普通停顿 / 中间夹纯标签句 / 结尾纯标签句 / 前导静音）全部符合预期。

## macOS 阅读区：换行时底色改成「滑动」补间（0.34s）
- 需求：一行播完切到下一行时，播放底色要「自然平滑地移动过去」，而不是灭一下/闪一下。
- 上一版的问题：底色是**每行各自一块**（`background(isActive ? accentWash : .clear)` + `.animation(0.18, value: isActive)`），两块视图之间只能「旧的淡出 + 新的淡入」——换行那一刻必然出现两个半透明块同时存在/交替，观感是闪。
- 改法（仅 macOS，`View/macOS/HistoryView/PlayerTranscriptView.swift`）：
  - 底色变成**整篇唯一一块**：`AlignedTranscript.highlightLayer(_:)` 画在内容 VStack 的 `.background(alignment: .topLeading)` 里，尺寸/位置由行 frame 决定。换行时只是这一块的 `offset`/`height` 变化 → SwiftUI 补间成一次连续位移（真·滑过去），左侧竖条同一块里一起走。
  - 行位置：每行 `.background { GeometryReader { $0.frame(in: .named(contentSpace)) } }` 上报 `TranscriptRowFrameKey`，落成 `@State rowFrames`。坐标系挂在**内容 VStack**（`(.coordinateSpace(name:)`）而不是视口 → 滚动不会改值，10Hz 播放路径里没有 preference 抖动。写入 state 前用 `sameFrames`（0.5pt 容差）挡掉亚像素抖动，避免「写 state→重排→再上报」自激。
  - `.animation(.easeInOut(duration: highlightTravel), value: highlight)` **只挂在底色这一层**；逐字高亮照旧不受影响。`scrollCurrent` 从 `.easeOut(0.22)` 改成 `.easeInOut(0.34)`，与底色同值同曲线 —— 两者同拍时视口正好把下一行送到上一行的位置，屏幕上底色几乎不动、只做高度过渡，不会出现「底色和文字互相追」。
  - 移除 `SentenceCueRow` 里的 `background` / `.animation(value: isActive)` / 竖条 `overlay`（`isActive` 仅剩时间码配色用途）。
- 验证：`bash tools/ios_build.sh mac` 双 target BUILD SUCCEEDED；另写 `/tmp/slide_demo.swift`（独立 SwiftUI 复现，动画放慢到 1.2s）连拍截图，确认中间帧的底板确实**横跨两行之间**（插值中），而不是两块独立淡入淡出。⚠️ 编译该复现脚本需 `swiftc -disable-sandbox -parse-as-library`（沙盒里 SwiftUI 宏插件起不来）。
- iOS `PlayerDetailControls.swift` 暂未改，用户仍要求先只做 macOS。
