## 修复：句卡只有 1 句（分句判据看错了标点位置）
- **现象**：273 字音频阅读区只有「273 字 · 1 句」，点哪都从头播。
- **根因**：上一版 `splitBySentenceEnding` 判据是 `word.text.last` 是否句末标点。实测上游把标点粘在**后一个字的前面**：`想`/`啥`/`呢`/`。"星`/`河`，所以 `word.text.last` 永远是汉字，除整段最后一个 word 外永不成立 → 只切出 1 句。
- **修法**：改为扫 word 的**前导标点簇**（`chars[p].isPunctuation`），切点落在簇内部；用 `inQuote` 状态机区分闭引号（`。"星` → 引号归前句）与开引号（`。"哥` → 引号留给后句）。只改 `text`，`beginMs/endMs` 一个不动（零估算）。

- **sidecar 迁移**：`AudioTimeline.currentVersion = 2`，`AudioTimelineStore.load` 检测到低版本就拍平 words 重切并回写，**用户不用重新生成音频**。⚠️ v2 产物不可再跑 v2 切分（标点已前移，重切会退化成一整段），已写进注释与 MEMORY。

## 修复：iOS 播放详情「文本卡与底部按钮之间空一大截」
- **根因不是 Spacer**：整页套 `ScrollView`、阅读区是**固定高度**（`metrics.height*0.42`）。ScrollView 内容高度只由子视图自然高度决定、永远填不满视口 → 「卡片底边 → 操作条」恒留 ≈40pt（固定阅读区 + 20pt Spacer + 操作条 10pt 内边距）。**只删 Spacer 无效**：空白会从「Spacer 撑的」变成「ScrollView 没填满的」，屏幕上一样空。
- **修法：按「谁负责滚动」拆两支**（`PlayerDetailView.page`）：
  - 对齐态（有 sidecar）：**删除整页 ScrollView**，改 `VStack(fixedBlocks + TranscriptCard.frame(maxHeight:.infinity))`。卡片拿到确定高度 → 阅读区 `frame(maxHeight:.infinity)` 真正吃掉剩余，卡片底边只留 `cardBottomGap = 8`（+ 操作条自身 10pt 内边距）。不依赖任何屏高常量。
  - 降级态（无 sidecar）：静态原文长度不可控，**必须保留整页滚动**。
- **`TranscriptCard.readerHeight` 类型 `CGFloat` → `CGFloat?`**：`nil` = 吃满剩余高度（新增 `ReaderHeight` ViewModifier，`.some` 仍固定）。⚠️ 用 Modifier 而不是调用处 if/else：内部 `ScrollViewReader` + `@State`（跟随/回中）换包装层会重置视图身份。
- **`timeline` 改在 `init` 里预热**（`_timeline = State(initialValue: item.timeline)`）：排版分支依赖它，等 `onAppear` 会先按降级排版铺一帧再换树 → push 动画里闪一下。`AudioTimelineStore.load` 带 NSCache，重复构造只是命中。
- 安全边界：iPhone 仅竖屏（`INFOPLIST_KEY_UISupportedInterfaceOrientations = Portrait`），iPad 四方向高 ≥834 → 最窄可视 ≈450pt，固定块 ≈270 + 卡片最小 56 = 326 < 450，不会溢出。⚠️ 若以后放开 iPhone 横屏，这支 VStack 需要重新评估。
- 验证：`bash tools/ios_build.sh mac` 双 target BUILD SUCCEEDED。
