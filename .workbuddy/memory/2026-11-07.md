## iOS 部署目标 18.6 → 17.6 兼容性审查（只做检查，未改代码）

- pbxproj 的 iOSEmora Debug/Release 两处已由用户改为 17.6（staged）；project 级只有 MACOSX_DEPLOYMENT_TARGET，不受影响。
- **编译层结论：无影响**。Debug(`bash tools/ios_build.sh`) + Release 真实构建均 `BUILD SUCCEEDED`，产物 `MinimumOSVersion=17.6`、target triple `arm64-apple-ios17.6-simulator`，日志零 `only available` 诊断；`swiftc -typecheck` 按 17.6 target 也 EXIT=0（仅既有 Sendable / 多余 await 两条 warning）。
- 源码**零** `@available` / `#available`（全量 grep），说明原本就没依赖任何 iOS 18+ API；用到的较新 SwiftUI API 只有 `symbolEffect` / `listSectionSpacing` / `contentMargins`（均 iOS 17.0），SF Symbol 名也都在 iOS 16 及以前。iOS 27.2 SDK 的 `MinimumDeploymentTarget=15.0`、Swift 并发 back-deploy 下限 15.0，故 `SWIFT_DEFAULT_ACTOR_ISOLATION=MainActor` / `SWIFT_APPROACHABLE_CONCURRENCY` 不受影响；SPM 依赖最低 iOS 16（supabase-swift 2.55.6）。
- ⚠️ **唯一实质风险是运行期 UI，不是编译**：`ScreenMetrics.tabBarClearance = isPadClass ? 18 : 58` 与 `RootTabView` 顶部更新横幅 `+8pt` 都硬编码了「iPadOS 18 标签栏在顶部」这一假设；iOS 17 的 iPad `TabView` 标签栏仍在**底部**，mini player / 撤销 Toast / 后台接收条会只抬 18pt 被标签栏盖住。修法：在 ScreenMetrics 加 `hasTopTabBar`（`isPadClass && ProcessInfo.operatingSystemVersion.majorVersion >= 18`），tabBarClearance 与 banner 顶部偏移都按它分流（17 走 58pt）。iOS 17 iPad 的 58 需真机微调。
- 配套漂移：`tools/ios_typecheck/typecheck.sh:55` 仍写 `-target arm64-apple-ios18.6-simulator`，应同步为 17.6（已用临时副本验证 17.6 下 typecheck 通过）。
- 验证限制：本机可用模拟器 runtime 最低 iOS 18.4，**没有 17.x 模拟器**；但 `~/Library/Developer/Xcode/iOS DeviceSupport/iPad7,3 17.7.10` 存在，可用该 iPad 真机验 UI。Xcode 27.2 是否仍支持 iOS 17 真机调试需实测。

## 收敛 UIBackgroundModes（收掉 11-04 的悬置项）

- `EmotionVoice/iOSEmora-Info.plist` 的 `UIBackgroundModes` 从 `audio/fetch/processing` 收敛为**只留 `audio`**。依据：`audio` 有真实调用链（`AudioPreviewPlayer+iOS.swift` 的 `AVAudioSession.setCategory(.playback, mode:.spokenAudio)` + 后台/锁屏播放）；`fetch`/`processing` 全工程零 `BGTaskScheduler` / `BGAppRefreshTask` / `BGProcessingTask` / `performFetch` / `BGTaskSchedulerPermittedIdentifiers`，是无效声明（App Store 审核风险）。TTS 后台接收靠 `UIApplication.beginBackgroundTask`，**不需要任何 background mode**。

- 验证：`plutil -lint` OK；`bash tools/ios_build.sh mac` 双 target 均 **BUILD SUCCEEDED**；产物 `UIBackgroundModes=["audio"]`、`MinimumOSVersion=17.6`；pbxproj 无 `SystemCapabilities` / entitlements，不会被 Xcode capability 面板写回。
- ⚠️ **构建期踩坑（与本次改动无关，但会复现）**：用户在 Xcode GUI 里把 `Package.resolved` 的 swift-asn1 从 1.7.3 升到 **1.7.4**（`917b472…`），同时给 scheme 加了 `language=en/region=US`；但三处 SPM git 缓存都没有 1.7.4 对象，`-skipPackageUpdates` 又阻止 fetch → `Could not resolve package dependencies: unable to read tree`。三处要分别补：`EmotionVoice/build/SourcePackages/repositories/`（GUI，普通仓库）、`/tmp/iOSBuildDD/SourcePackages/repositories/`（CLI iOS）、`/tmp/MacBuildDD/SourcePackages/repositories/`（CLI macOS，**bare mirror**，须 `git --git-dir=<dir> fetch origin --tags`，`git -C` 会报 not a git repository）。补完即构建通过；不要为此回滚用户的 `Package.resolved`。
