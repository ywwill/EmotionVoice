## 复盘：删除 `skipStep` / `longSkipStep` 两个私有常量

用户质疑「声明两个属性有什么意义」。评审结论：**意义不大，已删**，4 处改回 `player.skip(by: ±15/±5)` 字面量，与 macOS `PlayerTransportView` 写法一致。
理由：
1. 每个常量只被引用 2 次，且都是 ± 成对，没有「多处复用」的收益；
2. 数字语义已由 SF Symbol 名 `gobackward.15` / `gobackward.5` 表达，抽常量后变成两处各自维护，改图标忘了改常量就会静默错位；
3. 用户明确要求参考 macOS，而 macOS 就是字面量；
4. 更关键的是「半吊子抽象」：真正重复出现 15 的地方是 `AudioPreviewPlayer+iOS.swift` 的锁屏远程命令（`preferredIntervals=[15]` ×2、`engine.skip(by: ±15)` ×2），View 私有常量管不到，容易误导后来人以为改这里就能全局生效。

什么时候才值得抽：只有把步长上移到 `AudioPreviewPlayer` 层、`View` 与远程命令共用同一个 `static let remoteSkipSeconds` 时才有价值；那种情况下应同时改图标（或由数据驱动生成按钮），否则别抽。

验证：`bash tools/ios_build.sh` → BUILD SUCCEEDED / ✅ 全部构建通过。

## macOS 启动窗口：消除「先小窗、再全屏」的跳变

需求：macOS 打开时窗口先是小窗，随后才铺满屏幕。

根因：`WindowGroup` 按 ContentView 的 `.frame(minWidth:1000,minHeight:800)` 建窗并 orderFront；`WindowAccessor.makeNSView` 里用 `DispatchQueue.main.async` 延后一拍才 `setFrame(visibleFrame)`，那一拍正好落在窗口上屏之后。另外 SwiftUI 把窗口 frame 存进 UserDefaults（`"NSWindow Frame …"`），下次启动先恢复历史尺寸，进一步放大跳变。

改动（只动 `View/macOS/EmotionVoiceApp.swift`）：
- Scene 加 `.defaultSize(width:height:)`，用 `NSScreen.main.visibleFrame` 动态算，窗口出生即最终尺寸。
- 新增 `LaunchWindowSizing`：统一可视区域 / 最小尺寸 / 极小屏退化规则，Scene 与 WindowAccessor 共用，避免两处逻辑分叉导致二次调 frame。
- `WindowAccessor` 改为自定义 NSView 子类，在 `viewDidMoveToWindow()` **同步**配置（透明标题栏、背景色、minSize、frame 校正），去掉 async；frame 已相同就跳过，`setFrame(_, display:false)` 不强制同步重绘。
- `AppDelegate.init()` 清掉所有 `"NSWindow Frame "` 前缀的 UserDefaults 键；配置时 `setFrameAutosaveName("")`，保持「每次启动铺满可视区域」的语义。
- `LaunchWindowCoordinator` 兜底：万一窗口先上屏，先 `alphaValue=0`，配置完成后 0.12s 淡入；带 0.8s 超时恢复与启动 0.5s 时间窗，避免误闪或窗口一直透明。
  - ⚠️ AppKit **没有** `NSWindow.didBecomeVisibleNotification`（编译报 `type 'NSWindow' has no member`），改用 `NSWindow.didBecomeMainNotification` + `didBecomeKeyNotification`，selector 版同步接收。

验证（`swift` 脚本用 `CGWindowListCopyWindowInfo` 每 8ms 采样窗口 bounds，不需要辅助功能权限）：
- 改动前：`988x822 → 999x831` 逐步放大，`+0.086s` 突然跳到 `1728x1030`。
- 改动后：首帧即 `1728x1030 @ 0,33`（AppKit visibleFrame `1728x1030 @ 0,54` 的 CG 坐标），2.2s 内零变化。
- `xcodebuild -project … -scheme Emora -sdk macosx …` → **BUILD SUCCEEDED**（最终代码重新构建过一次）；测试实例已 kill，Xcode 临时开关按原值还原。

语义提醒：macOS 窗口尺寸**不由用户上次调整结果决定**。若以后要改成「记忆窗口尺寸」，需同时移除三处：启动清 key、`setFrameAutosaveName("")`、`.defaultSize(...)`。
