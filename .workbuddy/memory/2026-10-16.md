# 2026-10-16

## 采样率默认值改为 22050
- `Models/Constants.swift`：`defaultSampleRate` 由 48000 改为 22050。
- 影响面：`VoiceStudioViewModel.sampleRate` 初值、`AppState.defaultSampleRate` 的 UserDefaults 回退值
  → `VoiceStudioView.onAppear` 用它给 vm 赋值；`SettingsView` 的采样率选择器同样读 appState。
- 注意：AppState 优先读 `UserDefaults["defaultSampleRate"]`（>0 才生效），所以本机若此前选过采样率，
  改常量不会立即生效；清偏好命令：`defaults delete com.emotion.voice defaultSampleRate`
- 候选列表 `Constants.sampleRates` 未动（8000/16000/22050/24000/44100/48000）。

## 积分全链路改为 Double（按实际消耗计费，最多 2 位小数）
- 起因：VoiceStudio 输入几个字符也显示 2 积分——`CreditManager.calculateTTSCredits` 里有
  `max(100, characterCount)` 的 100 字符起扣门槛。用户要求「按实际消耗 + 余额也支持 2 位小数」。
- 去掉起扣门槛：`credits = 字符数 / 100 * rate`，再归一化到 2 位小数（CJK 字算 2 个字符单位，
  见 `TextSplitter.calculateCharCount`）。普通 2 分/百字 → 0.02/字符单位；复刻 5 分/百字 → 0.05。
- 新增 `enum CreditPrecision { static func normalize(_:) }`（CreditManager.swift），
  所有余额加减、消耗计算、云端回落都过一遍 `(v*100).rounded()/100`，避免浮点尾数。
- 类型改动：`CreditManager.balance: Int → Double`、`CreditResult.insufficientCredits(Double, Double)`、
  新增 `deduct(points: Double)`（原来的 `deduct(for:)` 转调它）；`CreditsService.balance/canConsume/
  consume/purchase` 与 `monthlyUsed` 都改 Double；`AppState.creditsBalance/monthlyUsed` 改 Double；
  `CreditServiceError`、`deductForTTS/refundTTS/estimateCredits/currentBalance` 改 Double。
- 云端：`UserCreditsModel.credits`、`SupabaseManager.updateCredits/addCredits/fetchCredits/initializeUser`
  全改 Double。**⚠️ 需要 Supabase 侧把 `user_credits.credits` 列改成 numeric(10,2)**，
  否则小数写入会被 PostgREST 拒（本地照常，下次启动会被云端旧整数值覆盖）。
  SQL：`alter table public.user_credits alter column credits type numeric(10,2) using credits::numeric(10,2);`
- 浮点比较统一带 1e-9 容差（`canConsume` / `hasEnoughCredits` / `checkCredits` / `deduct`），
  避免 0.30 余额扣 0.30 被判成不足。
- VoiceStudioView 生成按钮不再 `Int(points.rounded(.up))`，直接按小数 `canConsume(points)`；
  生成成功后 `deduct(points:)` 用与预估、入库 `pointsCost` 同一个值。
- UI：`CreditsView`/`CreditsPurchaseView`/`StatsView` 余额改走 `formatCredits()`；
  `AudioGenerationModal.remainingCredits` 改 Double，"剩余 %d 积分" 的本地化 key 改成 "剩余 %@ 积分"
  （zh/en 两份 strings 同步改）。
- 校验：swiftc -typecheck（同 10-15 的命令）0 error，warning 均为既有。
