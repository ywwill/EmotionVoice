## 音色搜索逻辑核查
- 搜索核心在 `VoiceService.matchesSearch`（纯内存匹配），匹配 4 字段：
  `localizedName`(名) / `localizedDesc`(特质) / `scene.displayName`(场景) / `lang.displayName`(语种)。
- 中英文环境：前两者走 `AppLanguage.isChinese` 选 name/nameEn、desc/descEn；场景/语种走 `.localized()` 跟随系统语言。排序 `sortKey = localizedName` 同样随语言。
- 筛选(chip)走 SQL `categoryPredicate`，只用语义 code 列（tier/lang_code/scene_key/age），与语言无关。
- 搜索时 `VoicesLibraryViewModel` 强制 category=nil，即在**全部**音色里搜，忽略选中 chip（chip 计数恒为全量，不受搜索词影响）。
- ⚠️ **拼音搜索实际未实现**：`VoiceService.swift:149-150` 注释说"顺手支持拼音搜索"，但全代码库仅此一处提及 pinyin，
  实现只用 `localizedCaseInsensitiveContains`，无任何 汉字→拼音 转换（无 CFStringTransform / 拼音库）。中文环境下输 "longan" 不会命中"龙安灵心"。注释属误导性/未完成项。
