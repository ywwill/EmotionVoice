## 音色搜索逻辑核查
- 搜索核心在 `VoiceService.matchesSearch`（纯内存匹配），匹配 4 字段：
  `localizedName`(名) / `localizedDesc`(特质) / `scene.displayName`(场景) / `lang.displayName`(语种)。
- 中英文环境：前两者走 `AppLanguage.isChinese` 选 name/nameEn、desc/descEn；场景/语种走 `.localized()` 跟随系统语言。排序 `sortKey = localizedName` 同样随语言。
- 筛选(chip)走 SQL `categoryPredicate`，只用语义 code 列（tier/lang_code/scene_key/age），与语言无关。
- 搜索时 `VoicesLibraryViewModel` 强制 category=nil，即在**全部**音色里搜，忽略选中 chip（chip 计数恒为全量，不受搜索词影响）。
- ⚠️ **拼音搜索实际未实现**：`VoiceService.swift:149-150` 注释说"顺手支持拼音搜索"，但全代码库仅此一处提及 pinyin，
  实现只用 `localizedCaseInsensitiveContains`，无任何 汉字→拼音 转换（无 CFStringTransform / 拼音库）。中文环境下输 "longan" 不会命中"龙安灵心"。注释属误导性/未完成项。

  状态会丢；且全局卡片要能从任意页面把弹窗唤回来。弹窗 overlay 也从 VoiceStudioView 移到 ContentView。

  用计数不用 Bool 才能连续两次生成各触发一次）、`generationStartedAt`（卡片与弹窗共用开始时刻）。
- ⚠️ **重开弹窗必须手动落完成态**：`AudioGenerationModal.onAppear` 里
  `if vm.generatedAudioURL != nil, !vm.isGenerating { isCompleted = true; audioDuration = vm.generatedAudioDuration; return }`。
  因为 `isCompleted` 原是靠 `.onChange(of: stats.progress)` 设置的，重开时 progress 已是 1.0，
  onChange 不会再触发 → 否则会停在"正在接收音频数据"的空壳界面、时长显示 00:00。

  padding 22 → `.padding(.trailing, 14).padding(.bottom, 14)`，宽度 268 → 236。
  ⚠️ **扫光条原来用 GeometryReader 量宽度 → 会贪婪吃掉 ZStack 给的全部空间，把卡片撑成满屏一条**
  （表现就是"居中漂浮"）。改为 `CardLayout` 常量写死宽度（236 / sweep 0.34×），
  ZStack(alignment:.leading) + 固定 `frame(width:height:2)` + `.clipped()` 裁溢出。
  → 通用教训：SwiftUI 里固定尺寸的小浮层不要用 GeometryReader，它会破坏自身 sizing。
- ⚠️ **居中的真正原因不是 padding，是 ZStack 尺寸**：ZStack 的 size 只等于子视图并集，不撑满父级。
  弹窗在场时靠弹窗里的 `Color(...).ignoresSafeArea()` 撑开（看着正常）；关掉弹窗只剩卡片时
  ZStack 缩成卡片大小，而 `.overlay { }` 默认 alignment = .center → 卡片被摆到屏幕正中，
  `ZStack(alignment: .bottomTrailing/.topTrailing)` 完全失效。
  修法：给 ZStack 加 `.frame(maxWidth: .infinity, maxHeight: .infinity)`。
- 最终位置（用户要求）：内容区**右上角**，`top/trailing` 各 15（与工作台 `.padding(.vertical/.horizontal, 15)`
  同一条基线，即与文本编辑区卡片顶部齐平）；右侧列垂直居中，这块上方是空白，不压控件。
  插入动画同步改为 `.move(edge: .top)`。

  7 个拟声标签宽屏下排不满一行，右侧是空的，卡片落在空白里不压标签。
  全局浮层 `GenerationOverlay` 只保留**弹窗 + 失败 alert + 完成信号 onChange** ——
  这三类是"切到任何页面都必须出现"的；卡片只在语音合成页有意义。
