## 五语种音色名：把「死文件」变成正式的 8 语种音色目录

### 需求与决策
- 用户要求：`VoiceCatalog.strings` 的音色名按每个音色的描述特色 feature，生成 fr/de/ja/ko/ru 对应名称，**不是简单翻译**。
- 三个确认项全选推荐：① 生成名字并接通 Swift 运行时；② 意象式本地名（呼应中文三字诗意名）；③ 特质文案一起本地化。
- 起点核实：`4b61a21 德法俄日韩` 已把 5 份 `.strings` + pbxproj 的 5 个 PBXFileReference / 变体组 children 恢复（staged A），但内容是 `en.lproj` 逐字副本；Swift 仍是 zh/en 二值（`lprojCandidates` 非 .zh 返回 `["en"]`），`rowToVoice` 只烘焙 `name/nameEn`，**五份运行时读不到**。`tools/gen_basic_voices.py` 白名单仍是 3 份，同批 staged 改动只是 `SRC_JSON` 补 `Shared/` 路径。
- 数据：599 音色（591 zh / 8 en；419 female / 179 male / 1 unknown），180 种唯一 feature（中英一一对应），zh/en 名字各 599 全唯一。

### 命名方案
- 180 个中文 feature **显式**映射到 17 个语义族（warm / resonant / calm / bright / lively / wise / mature / broadcast / magnetic / cute / fear / dark / sad / passion / scene / wuxia / plain），不用关键词规则，零歧义。
- 名字 = 语义族意象词根 + 该语种人名化名尾；按 `(族, 性别)` 分组、按 idx 顺序确定性分配，suffix-major（先换词根，避免同族前几个名字长一个样），全局去重兜底。词根按族隔离，跨族天然不撞名。
- 各语种构词：日语「意象汉字 + 和风名尾」（優奈 / 光央）、韩语「固有词 + 名尾」（온유 / 햇도）、德语日耳曼复合名（Lindhild / Klarfried）、法语 -ine/-ette 派生（Doucée）、俄语 -ана / 男声「连接元音 о + 斯拉夫成分」（Нежнена / Нежномир）。
- ⚠️ 生成器 `join_name()`：**法语**词根与名尾都以元音起止时剥掉词根末尾元音串（Douce+ée → Doucée，不是 Douceée）；**俄语男声**词根以辅音收尾时插连接元音 о（Пыл+мир → Пыломир，不是 Пылей）。改词库必须记得这两条，否则又会出现生硬拼字。
- 校验：599×5 全唯一；最长 fr 12 / de 14 / ja 2 / ko 3 / ru 13 字符。

### 音色卡片 UI 重设计（macOS，输出 HTML 设计稿，⚠️ Swift 代码未改）
- 交付 `UI/macOS/voice-card-redesign.html`（单文件、无外部依赖、可交互）。用户三项诉求：名字一行显示不全 / 移除旗舰标识 / 重新设计卡片。
- ⚠️ 根因实测（220px 卡，`Chrome headless` 真实 DOM 测量，不是估算）：`VoiceCard.nameRow` 里 `Text(name).lineLimit(1)` 与 `metaTags.fixedSize(horizontal:true)` 同行，fixedSize 先占宽 → 名字可用宽度随界面语言塌缩：**112px(zh) / 75px(en) / 48px(de) / 68px(ru)**；最长名 `Величествомир` 15px/600 实测 116px。德语 meta 是 `25 Jahre / Weiblich`，连 4 字中文名都截断；320px 宽卡旧版反而不截断 → 问题随语言与卡宽随机出现，中文界面验收容易漏掉。8 语种界面铺开后才暴露。
- 新方案：名字独占 192px 全宽（与界面语言解耦）、`lineLimit(2)` + `minimumScaleFactor(0.88)`、名称区固定 38pt + 卡片固定 180pt 保证 LazyVGrid 等高；meta 下移独立一行并去掉 `.fixedSize(horizontal:true)`；头像 40→32；收藏从 actionRow 上移到身份行右上；操作行 `Spacer(minLength:0)` 贴底；`cardBackground` 统一纯 `bgSecondary`，不再按 tier 渐变。
- 旗舰标识删除清单（设计稿 change log 有完整表）：`VoiceCard.header` 的 `⭐ 旗舰`、`VoiceCardItem.isPremium`、`VoiceCardSkeleton` 占位 `tier:.premium→.basic`、`cardBackground` 的 tier 差异；筛选维度保留但 `⭐ 旗舰音色 → ◇ 高规格音质`；`UI/macOS/voices.html` 的 `.voice-tag.premium`/`.featured` 需同步。
- 验证：Chrome `--dump-dom` 渲染 20 张卡片、无 undefined/NaN、无 JS 报错；CDP 实测语言/宽度切换、选中/试听/收藏/使用全通；德语与俄语界面下旧版 4 张卡 3 张截断、新方案 4/4 完整，320px 下旧版 0 截断（与上方根因一致）。⚠️ 压力测试旧版判定必须在元素挂入 document **之后**读 `scrollWidth`，detached DOM 恒为 0 会误判「未截断」（本页已修）。
