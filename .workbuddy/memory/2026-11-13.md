## 五语种音色名：把「死文件」变成正式的 8 语种音色目录

### 需求与决策
- 用户要求：`VoiceCatalog.strings` 的音色名按每个音色的描述特色 feature，生成 fr/de/ja/ko/ru 对应名称，**不是简单翻译**。
- 三个确认项全选推荐：① 生成名字并接通 Swift 运行时；② 意象式本地名（呼应中文三字诗意名）；③ 特质文案一起本地化。
- 起点核实：`4b61a21 德法俄日韩` 已把 5 份 `.strings` + pbxproj 的 5 个 PBXFileReference / 变体组 children 恢复（staged A），但内容是 `en.lproj` 逐字副本；Swift 仍是 zh/en 二值（`lprojCandidates` 非 .zh 返回 `["en"]`），`rowToVoice` 只烘焙 `name/nameEn`，**五份运行时读不到**。`tools/gen_basic_voices.py` 白名单仍是 3 份，同批 staged 改动只是 `SRC_JSON` 补 `Shared/` 路径。
- 数据：599 音色（591 zh / 8 en；419 female / 179 male / 1 unknown），180 种唯一 feature（中英一一对应），zh/en 名字各 599 全唯一。

### 命名方案
- 180 个中文 feature **显式**映射到 17 个语义族（warm / resonant / calm / bright / lively / wise / mature / broadcast / magnetic / cute / fear / dark / sad / passion / scene / wuxia / plain），不用关键词规则，零歧义。
- 名字 = 语义族意象词根 + 该语种人名化名尾；按 `(族, 性别)` 分组、按 idx 顺序确定性分配，suffix-major（先换词根，避免同族前几个名字长一个样），全局去重兜底。词根按族隔离，跨族天然不撞名。
- 各语种构词：日语「意象汉字 + 和风名尾」（優奈 / 光央）、韩语「固有词 + 名尾」（온유 / 햇도）、德语日耳曼复合名（Lindhild / Klarfried）、法语 -ine/-ette 派生（Doucée）、俄语 -ана / 男声「连接元音 о + 斯拉夫成分」（Нежнена / Нежномир）。
- ⚠️ 生成器 `join_name()`：**法语**词根与名尾都以元音起止时剥掉词根末尾元音串（Douce+ée → Doucée，不是 Douceée）；**俄语男声**词根以辅音收尾时插连接元音 о（Пыл+мир → Пыломир，不是 Пылей）。改词库必须记得这两条，否则又会出现生硬拼字。
- 校验：599×5 全唯一；最长 fr 12 / de 14 / ja 2 / ko 3 / ru 13 字符。
