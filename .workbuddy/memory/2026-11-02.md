## 音色库筛选交互（VoicesLibraryView / VoicePickerSheet / CategoryFilterSheet）
- 分类按钮整条胶囊全热区：外层容器 `.contentShape(Rectangle())` + `.onTapGesture`（原来是内部 Button，右侧 chevron 区和左侧留白点不动）。**选完分类不再出 ×**：清除走分类列表里的「全部音色 / 重置」。`VoicePickerSheet` 同步改掉（它还有 `if selectedCategory != nil { Button(xmark) }`）。
- 刷新过渡动画：`CategoryFilterSheet.onCommit` 改成 `(_ dismissing: Bool)` —— 点行即收起时外面**延迟 0.25s** 再刷新（同步刷新的话动画全程盖在 Sheet 背后，只剩硬切），「重置」不收起 → 立即刷新。
- ⚠️ 过渡本体不用容器 `.transition`：`.id(scrollResetID)` 重建触发的 transition 不保证触发。改成 `contentVisible` 驱动 `opacity` + `offset(y:12)`：淡出 0.1s → 换数据 + 复位滚动 → 淡入上浮 0.28s（`swapAnimation`）。两份视图一致；取消淡出的 Task 后要把 `contentVisible` 置回 true，否则列表停在透明状态。
- 验证：`bash tools/ios_typecheck/typecheck.sh` 无 error。

## 分类列表进出场动画
- `VoicePickerSheet` 的分类列表是 `if/else` 就地替换（不套第二层 Sheet），原本**没有任何动画** → 加 `panelTransition`（`move(edge:.bottom)` + `opacity`，进出同向）+ `openCategoryList()/dismissCategoryList()` 里的 `withAnimation(panelAnimation)`，外层再挂 `.animation(panelAnimation, value: categoryPresented)`。⚠️ else 分支的多个视图必须包一层 VStack，逐个挂 transition 会各自为政。
- `CategoryFilterSheet` 自身补进场：内容 `offset(y:14)` + `opacity` → 0，`onAppear` 里 `withAnimation` 置位；⚠️ 必须 `.onDisappear { appeared = false }` 复位，否则第二次打开不再有进场动画。
- `VoicesLibraryView` 那边是系统 `.sheet`（自带上滑），只给胶囊加了 `.animation(.easeOut(0.22), value: selectedCategory)` 让底色/描边/计数过渡。
