# Domain Docs

Single-context layout: one `GLOSSARY.md` and `docs/adr/` at the repo root.

## Consumer rules

Skills that need shared vocabulary read from:

- `GLOSSARY.md` at the repo root
- `docs/adr/*.md` for Architecture Decision Records

Skills that write domain docs:

- `domain-modeling` skill writes to `GLOSSARY.md`
- `domain-modeling` skill writes ADRs to `docs/adr/`
