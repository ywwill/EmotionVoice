600 音色选择器 UI 设计方案

你是一名资深 SaaS / AI 产品 UI/UX 设计师，同时也是高级前端工程师。

请为一个「AI 文字转语音 / TTS 音色选择器」设计并实现一个高质量、现代、专业、可直接运行的 HTML 单页面原型。

一、产品背景

这是一个 AI 文字转语音 App，当前有约 600 个音色。

用户需要从 600 个音色中选择一个进行语音合成。

每个音色包含以下信息：

* 名称
* 描述
* 标签
* 年龄
* 性别

同时，每个音色都应该有：

* 试听按钮
* 收藏按钮
* 当前选中状态

核心问题：

600 个音色数量非常大，不能简单地将所有音色无脑平铺，否则用户很难找到合适的音色。

因此设计重点必须是：

1. 快速找到音色
2. 快速试听
3. 快速筛选
4. 快速比较
5. 收藏常用音色
6. 让 600 个音色看起来不会产生信息过载
