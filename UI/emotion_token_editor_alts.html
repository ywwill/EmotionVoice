EmotionTokenEditor · 替代方案对比 3 个方向

第一版（内联彩色胶囊）是最直接的方案。下面是 3 个结构不同的替代方向， 同样遵循 Apple HIG + 真实情绪色板 + 明暗自适应。每个都可交互试用，挑一个我们落地。

A

情绪下划线（无胶囊框）

文本保持自然流式，情绪以「彩色下划线 + 行内 emoji 标记」呈现，不破坏阅读节奏。最干净的「一般」感。
今天的会议😮太顺利了，大家× ⚡兴奋得想× 😆大笑，不过× 😢悲伤的是排期延期，× 😐严肃复盘一下。×

B

极简色点标签（低彩噪）

保留内联标签，但去掉整片彩色填充——只用一个 8px 情绪色点 + 中性文字。颜色降到「提示级」，界面最安静。
今天的会议😮惊叹×太顺利了， 大家⚡兴奋×得想 😆大笑×， 不过😢悲伤×的是排期延期， 😐严肃×复盘一下。
点击标签选中 · 悬停 × 删除 · ⌫ 删除选中142 字
C

纯文本 + 下方情绪时间轴

上方是纯净文本域（情绪仅以细微 emoji 标记），下方一条「情绪时间轴」按出现顺序展示所有标签，便于总览 / 重排 / 删除。
今天的会议😮太顺利了，大家⚡兴奋得想😆大笑，不过😢悲伤的是排期延期，😐严肃复盘一下。

怎么选
· 想要最干净、阅读优先 → A 情绪下划线（文本不被方框打断）。
· 想要界面最安静、颜色仅作提示 → B 极简色点。
· 想要总览 + 易重排/删除 → C 情绪时间轴（占空间，但结构最清晰）。
· 若仍偏好最直接、情绪最强 → 回到第一版内联彩色胶囊。
三者删除交互一致：悬停 × 或选中 + ⌫。确认后我再落地 SwiftUI。
