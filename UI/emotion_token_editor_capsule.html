v11 语气胶囊版的设计要点
① 胶囊承载作用域：一个语气标签的文本整段落在同色胶囊里（填充 = 情绪色 13%，1px 内描边 42%，圆角 9， 左右内边距 7）。颜色本身就是「这段用什么语气」的信号，比单一的下划线信息量更大。
② 徽章在左上角：emoji + 名称（10.5px、加粗）压在胶囊左上角（底色取编辑器背景 + 情绪色描边， 保证在任何文本上都读得清）。它只出现在作用域的首块，续段不再重复。
③ 跨行：胶囊按「行片段」分块绘制，每块各自圆角与内边距（对应实现里的 enumerateLineFragments + boundingRect），不会出现一整块畸形的大圆角。
④ 拟声不打断语气：声音标记嵌在语气胶囊内部继续着色（示例里「大笑」两侧仍是惊叹紫）， 它自己保持虚线 + 悬停居中 × 的形态。
⑤ 接缝天然形成：相邻语气各自一个胶囊，中间 3px 间隙即可分开，不再需要「下划线内缩」的小技巧。
⑥ 删除交互：悬停胶囊或徽章 → 徽章右侧浮出 ×（悬停区 = 胶囊 ∪ 徽章 ∪ ×，避免移过去就消失）； 拟声仍是悬停 → 正中浮出 ×；两者都支持选中 + ⌫。
⑦ 仍需留意的两点：徽章压在首行上方需要顶部留白（实现上 textContainerInset 至少 18pt）； 行尾的徽章要像标注那样做右边界回缩，否则会被容器裁掉（v10 已解决过同类问题）。

· 行距加大：bodyAttributes.lineSpacing 12 → 18，给胶囊与徽章留出呼吸位
