信息架构：macOS 侧边栏 → iOS 标签栏

功能 1:1 对齐，只重组容器。macOS 是「220pt 侧边栏 + 1500×900 内容区」的单窗口多分区；iOS 改为 3 个标签 + 导航栈，标签栏只放三个高频主任务 —— 创作 / 音色库 / 项目，二级内容用 push / sheet 承载。macOS 的 5 个分区里，「语音合成 / 音色库 / 我的项目」各自成为独立标签；「积分中心」整个搬进「设置」（设置页顶部就是购买入口），设置入口 = 三个标签导航栏右上角的齿轮，push 进当前标签的导航栈。

iOS 适配原则
  • 去掉 hover / 光标 / tooltip：所有 hover 才出现的 ×、描边、背景一律改为常显或按压态；23 个语气的 description 从 tooltip 改为标签面板里的副行。
  • 去掉快捷键：空格 / ←→ / Home·End 全局热键与底栏键帽提示全部移除，改为屏上控件。
  • 文件面板 → 分享面板：`NSSavePanel` 换 `fileExporter` + `UIActivityViewController`；删除「在 Finder 中显示」。
  • popover → sheet：4 处说明弹窗（语气 / 中断 / 拟声 / 指令指南）改为 sheet 或可折叠面板。
  • 桌面专属项直接删：主题 / 语言交给 iOS 系统设置，导出走分享面板没有常驻目录，缓存交给系统，设备标识随 Keychain —— 设置页只留账户 + 语音合成 + 关于。
  • 编辑器重做：`NSTextView` → `UITextView`；键盘避让 + inputAccessoryView 承载标签栏。

创作工作台（对应 macOS「语音合成」）

macOS 的左右两栏（左 980pt 编辑区 + 右 350pt 参数栏）在 iPhone 上收成单列：导航栏常驻积分 / 顶部音色行 / 文本卡（主内容）/ 参数摘要条 / 底部生成条。右侧三张参数卡（音色切换、音频控制、语音指令）合并成一张 medium detent 的参数 Sheet；23 个语气 + 7 个拟声从常驻网格改为键盘 accessory 上的横向标签条，编辑 Focusing 时才出现。

生成、接收与后台续跑

macOS 的生成弹窗是 560pt 居中卡片 + 全屏遮罩，iOS 直接沿用这个思路：331pt 居中弹窗 + 虚化遮罩，点「生成音频」当场弹出，不再推 Sheet、不再单开一屏。接收中与完成态共用同一个弹窗，只切换顶部渐变条、图标与内容区。
弹窗内部按「7 层信息」填满——音色 × 参数 chips（含本次计费）、实时波形、大字字节数 + 速率、不确定进度条、四宫格（已用时 / 数据块 / 目标大小 / 预计时长）、接收网格、后台接收 / 停止生成，避免大面积留白。macOS 里锚在「拟声效果」右下角的后台接收卡（236pt）在 iOS 上改为浮在内容顶部的全宽条，任何标签页可见。

音色库

分类体系完全照 Swift 源码（Models/Voice.swift 的 VoiceCategory / VoiceCategoryDimension）：29 个分类 case，按 5 个维度分组 —— 旗舰（1）/ 语言（2）/ 适用场景（17）/ 角色（4）/ 年龄阶段（5）；再加上视图层单独渲染的「收藏」「全部」，一共 31 项。

macOS 把这 31 项排成两行 FlowLayout（横向约 1400pt），iPhone 只有 371pt，横滚两行既看不全也不好点，所以 iOS 取消横向 chip 模块，改成一个分类按钮：默认显示「全部分类 · 599」，点一下弹出全部分类 Sheet。

选中结果必须回显在两个地方：① 音色库列表的按钮变成所选分类本身（图标换成该分类 emoji + 名称 + 命中数 + ✕）；② 再次打开 Sheet 时，上次所选的那一整行右侧打 ✓、底色转强调，顶部还有一条「当前选择」吸顶条可一键清除 —— 来回进出 Sheet 不会丢选择。

以下 7 条交互规则全部来自源码，iOS 不改语义：① 分类是单选——selectCategory 互斥，选中新项即取消旧项，再点一次同一个才回「全部」；② 分类与「仅收藏」互斥（选分类会清收藏筛选，反之亦然）；③ 每行数字恒为全量统计（reloadChipCounts 始终用空搜索词），不随搜索框输入变化；④ 搜索时忽略当前分类，在全库范围内匹配；⑤ 搜索只命中 4 个字段（当前语言的音色名 / 特质描述 / 场景名 / 语种名）；⑥ 排序固定为「旗舰优先 → 展示名字典序」，没有排序控件，也没有语速/音调范围滑杆（RangeSlider.swift 是未挂载的孤儿文件）；⑦ macOS 分页 pageSize = 列数 × 4，iOS 改为上拉追加。

我的项目 → 播放详情

macOS 是「左 340pt 列表 + 右详细信息」两栏同屏；iOS 改为 push 导航栈，列表页用 .searchable，点任意行「选中即播放」并 push 详情。右键 popover 菜单（批量操作 / 编辑名称 / 导出 / 复制 / 删除）改为左滑 Swipe Actions + 右上角「选择」进入多选；底部状态栏的快捷键键帽全部移除，只保留播放状态。

设置与账户（原「我的 / 积分中心」并入）

标签栏只保留 3 个主任务——创作 / 音色库 / 项目；macOS 的「积分中心」不再单独占一个标签，而是整块搬进设置页，设置入口 = 三个标签导航栏右上角的齿轮（push 进当前标签的导航栈，返回键回到该标签）。

设置页顶部就是购买入口：一张账户卡（当前余额 + 永久有效 + 计费规则 + 「购买积分」主按钮），点卡上的按钮直接弹出购买 Sheet；下面一行是「积分记录 · 128 条 ›」，点进去是独立的二级列表页。

按你的要求，macOS 设置里的主题 / 语言 / 导出目录 / 自动清理缓存 / 设备标识 五组全部删除（iOS 的外观与语言由系统设置接管，导出走分享面板没有常驻目录，缓存交给系统，设备标识随 Keychain 走），设置页只留：账户（购买 + 记录）· 语音合成（默认格式 / 采样率）· 关于（版本）。

计费规则与 macOS 完全一致：2 积分 / 100 字符（中日韩按 2 字符、英文数字标点按 1 字符计），余额与流水一律 Double、最多 2 位小数，无起扣门槛。原 macOS 的分页条改为 iOS 的上拉追加。

设计系统：Aurora Pop · iOS 版

v2 换掉了 macOS 的「冷调中性底 + 琥珀金」，改为 Aurora Pop：雾紫中性底（浅色 #F5F1FE / 深色 #0B0916）+ 紫 · 玫瑰 · 薄荷 · 暖橙 四色强调，渐变优先。中性面全部走 iOS 语义色（背景 / 分组背景 / 卡片三级）并做系统动态色；右上角开关可整体切换浅色 / 深色，所有手机稿与色板同步变化。

颜色令牌（浅色 / 深色）

中性底色统一偏紫（浅色 —bg-grouped #F5F1FE，深色 —bg #12101F），比原来的纯灰更年轻，但明度结构不变，三级文字仍在 4.5:1 以上（浅色 #736D8F 4.9:1 / 深色 #8E86B0 5.1:1）。
承载文字的强调色与承载面积的渐变色拆成两套：文字强调浅色 #6D3BF5（白底 5.9:1）、深色 #B79AFF（底 8.2:1）；按钮渐变走深一档的紫→玫瑰（浅色 #5B2EDB→#CE2B72，白字 4.5–7:1），把更亮的 #8A5BFF / #FF5FA2 留给装饰、发光与接收网格。

待你确认的 5 个决策点

  1. 已定稿：标签栏 3 个（创作 / 音色库 / 项目），「积分中心」并入设置页顶部。若日后觉得余额不够显眼，可在「创作」导航栏的余额胶囊上加一个「充值 ›」尾随入口，不必再起第 4 个标签。
  2. 情感标签是 accessory 滚动条还是 Bottom Sheet？现方案是键盘 accessory（边写边插最快），也可换成独立 Sheet。
  3. 音色网格是否保留 2 列？可选紧凑单列列表，更能装下两行特质描述。
  4. 是否给 iOS 补上「音色详情 / 场景标签」？macOS 版两者都没有（sceneTag 有样式但没挂载）。
  5. 是否需要 iPad 适配？若有，两个标签页可直接升级为 NavigationSplitView 复用 macOS 的两栏。
  6. 完成态是否留在弹窗里？现方案是同一个居中弹窗切换为完成态（含播放器 + 分享/导出/完成）；若觉得挤，可改成完成后自动 dismiss 并 push 到「项目」里的播放详情页。
