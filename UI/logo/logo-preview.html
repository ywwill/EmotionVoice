EmotionVoice 图标设计

这一版抛弃了均衡器式的声波。产品真正的核心动作不是「播放声音」，而是把情感调到想要的位置——所以图标是一枚可以被你拧动的旋钮。

The Emotion Knob

情感旋钮 · 一枚精密的情感控制器

金色金属旋钮坐在深冷黑的腔体里，四周是 13 个刻度点铺开的 300° 行程，把手停在两点钟方向——情感正在被调高。

它对应的是产品里最真实的交互：音色编辑器中的情感强度、语速、音调。EmotionVoice 让「情感」变成一个可以精确调节的量。

构成解析

四层叠加，从背景到主体，每一层承担一个语义。

LAYER 01

深空冷黑腔体

#1A1D24 → #0A0B0E。深夜录音棚的颜色，让金属获得最大对比。

LAYER 02

中心暖光

琥珀色光晕从旋钮背后渗出，暗示这台设备是「通电工作」的。

LAYER 03

刻度行程

13 个刻度点铺开 300°，从克制到饱满，给「情感量」一个可读的刻度。

LAYER 04

金属旋钮

偏心径向渐变做出球面感，机加工同心纹、倒角亮边与镜面高光，让它像一块真实的车削金属。

在 Dock 中的样子

约 64pt，与相邻图标并排的实际观感（其余方块为占位示意，同样保留 macOS 图标留白）。

一整圈金色是 Dock 里少见的做法。它不会和蓝色系的系统图标抢视觉，但会是那排图标里唯一一个「温的」。

其他方向（可随时切换）

同一套配色下的另外两个器物隐喻，作为备选保留。

Reference Monitor 监听音箱。指向「专业录音棚」的定位，器物感最强。
Emotion Chip 情感胶囊。取自产品独有的 EmotionToken，正文中嵌入的情感标记。
怎么换？ 告诉我选哪个方向，我用同一套几何引擎重新出全套尺寸与图标集，几分钟的事。

与旧图标对比

旧版是粉紫橙渐变加爱心波形，跟产品 UI 的冷调设计语言完全脱节，也是同类 App 里最常见的符号。

旧版 暖色渐变 · 与 UI 色系脱节 · 通用爱心语音符号
新版 · The Emotion Knob 冷调腔体 + 金属琥珀金 · 与 UI 同源 · 独一无二的器物符号

技术规格
